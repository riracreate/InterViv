# SemEval-2013 Task 7 normalized data

The sibling JSONL files are format-normalized adaptations of the BEETLE and SciEntsBank `Core` test partitions from SemEval-2013 Task 7. They exclude training data and the `Extra` facet files.

- Source: <https://github.com/myrosia/semeval-2013-task7>
- Source revision: `5157c69f914e8c581045c03e98f96398d40a91b8`
- Original task: [Dzikovska et al., SemEval 2013](https://aclanthology.org/S13-2045/)
- License: [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/)
- Modification notice: the organizer XML was transformed to the grader-lab JSONL schema, reference answers were retained as an array, stable concept IDs were derived from reference-answer content words, and source paths/revision were added as metadata.
